# sodamsa-assets

온라인 법당 [소담사](https://sodamsa.kr) 의 3차원 법당(https://hall.sodamsa.kr)이 쓰는 큰 정적 자원입니다. 법당은 이 파일들을 jsDelivr 로 받습니다.

| 파일 | 내용 | 출처와 이용 조건 |
| --- | --- | --- |
| `buddha.2ddd2d28.glb` | 본존 불상 3D (9.9만 삼각형, meshopt 압축, ETC1S 2048 텍스처) | 국가유산청 「경주 왕룡사원 목조아미타여래좌상」 3D 모델링, [공공누리 제1유형](https://www.kogl.or.kr/info/licenseType1.do) (출처 표시). 원본을 줄이고 압축했습니다 |
| `yeongsan.aea91d12.ktx2` | 탱화 (4096x1632, UASTC RDO 4, zstd) | 클리블랜드 미술관 1918.541 「석가모니설법도」 (조선 1846), [CC0](https://www.clevelandart.org/open-access) |

- 파일 이름의 8자리는 sha256 앞자리입니다. 내용을 바꾸면 이름을 바꾸고 새 태그를 붙입니다. 이미 붙인 태그의 파일은 바꾸지 않습니다
- 서버 `hall/assets/` 에도 같은 파일이 있습니다. jsDelivr 에서 받지 못하면 법당이 그쪽으로 다시 받습니다
